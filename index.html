01 · Struct
ESTRUTURAS HETEROGÊNEAS — NOVOS TIPOS DE DADOS
"A utilização de vetores e matrizes implica em manipular uma grande quantidade de dados por meio de acesso indexado, no entanto, até então, tínhamos a limitação de que todos os elementos deveriam ser do mesmo tipo." — Prof. Moreno
Conceito
O que é Struct?
Uma coleção de variáveis, possivelmente de tipos diferentes, agrupadas sob um único nome. Permite criar novos tipos de dados além dos primitivos da linguagem.
Motivação
Por que usar?
Imagine uma ficha cadastral: nome, CPF, telefone, idade. São tipos diferentes relacionados entre si. A struct une tudo em um único tipo coeso.
Acesso
Operador ponto (.)
Variável normal usa pe.nome. Ponteiro para struct usa pe→nome (equivale a (*pe).nome).

Sintaxe e Anatomia

Forma Geral
C · struct // Declarada GLOBALMENTE (antes do main)
struct Pessoa {
    char nome[50]; // 50 bytes
    char fone[16]; // 16 bytes
    int idade; // 4 bytes
};

// Com typedef — mais conveniente:
typedef struct {
    char nome[50];
    char fone[16];
    int idade;
} Pessoa;

// Sem typedef → struct Pessoa pe;
// Com typedef → Pessoa pe; ← mais limpo!

Regra 2: Tamanho total da struct deve ser múltiplo do maior tipo dos membros.

Vetor de Struct

Array
C Pessoa pe[5]; // 5 elementos do tipo Pessoa
pe[0].nome = "Ana"; // acesso: índice + ponto + campo
pe[0].idade = 21;

// Copiar struct inteira de uma vez:
pe[1] = pe[0]; // copia TODOS os campos !

Aninhamento de Structs

Nested
ℹ Uma struct é um tipo de dado. Logo, ela pode conter variáveis de outras structs previamente definidas.
C typedef struct { int dia, mes, ano; } Data;

typedef struct {
    char nome[50];
    Data nascimento; // struct dentro de struct!
} Aluno;

Aluno a;
a.nascimento.ano = 2002; // acesso encadeado
02 · Ponteiros
VARIÁVEL QUE GUARDA UM ENDEREÇO DE MEMÓRIA
"Um ponteiro é uma variável que armazena o endereço de memória de outra variável. Em outras palavras, um ponteiro 'aponta' para a localização de outra variável na memória do computador." — Prof. Moreno (citando Tenenbaum, 1995)
Tamanho
32 bits = 4 bytes
64 bits = 8 bytes
Todo ponteiro ocupa o mesmo espaço, independente do tipo que aponta. O tipo determina como a leitura/escrita é feita.
Operadores
& e *
& obtém o endereço de uma variável.
* desreferencia — acessa o conteúdo do endereço apontado.
Vetor
Vetor = Ponteiro
O nome de um vetor já é um ponteiro para o seu primeiro elemento. scanf("%s", nome) funciona sem & por isso.

Como declarar e usar

Sintaxe
C int x = 22; // variável normal
int *ptr_x = &x; // ptr_x aponta para x

printf("%d", x); // 22 — valor de x
printf("%p", &x); // 0060FEF0 — endereço de x
printf("%p", ptr_x); // 0060FEF0 — conteúdo do ptr
printf("%d", *ptr_x); // 22 — valor apontado

*ptr_x = 100; // altera x PELO ponteiro
printf("%d", x); // 100 — x foi modificado!

Visualização na Memória (32 bits)

Diagrama
Variável x (int, 4 bytes) e ponteiro ptr_x (int*, 4 bytes):
x 22 0060FEF0
  ··· …
ptr_x 0060FEF0 0060FEF4
*ptr_x → acessa x (valor 22)

Ponteiro como Parâmetro

Passagem por Referência
ℹ Em C, funções só retornam um valor. Com ponteiros como parâmetros, você pode "retornar" múltiplos valores modificando variáveis por referência.
C · swap void troca(int *a, int *b) {
    int aux = *a;
    *a = *b;
    *b = aux;
}

// Chamada — envia ENDEREÇOS:
int x = 10, y = 20;
troca(&x, &y); // x=20, y=10 após retorno

Ponteiro para Struct

Operador →
⚠ Ao acessar dados de um ponteiro para struct, o ponto (.) é substituído por seta (→). Isso é necessário pois estamos trabalhando com um endereço de memória.
C Pessoa pe = {"Ana", "9999-0000", 21};
Pessoa *ptr = &pe;

// Formas EQUIVALENTES de acessar:
printf("%s", pe.nome); // via variável
printf("%s", ptr->nome); // via ponteiro (→)
printf("%s", (*ptr).nome); // via ponteiro (equivalente)

Ponteiro para Ponteiro

**
C int a = 22;
int *b = &a; // b aponta para a
int **c = &b; // c aponta para b

printf("%d", a); // 22
printf("%d", *b); // 22
printf("%d", **c); // 22

// Também existe: int ***d (triplo ponteiro)
a 22 0060FF24
b (int*) 0060FF24 0060FF20
c (int**) 0060FF20 0060FF1C
03 · Aritmética de Ponteiros
NAVEGANDO PELA MEMÓRIA COM PRECISÃO CIRÚRGICA
"Não será somado o valor 1 ao endereço, mas sim, como o tipo do ponteiro é int, ele somará 4 bytes que é o tamanho de 1 int." — Prof. Moreno
Operações válidas
+, −, ++, −−
Apenas adição, subtração e incremento/decremento. Multiplicação e divisão NÃO fazem sentido para endereços.
void pointer
void* — Cuidado!
Ponteiro genérico não suporta aritmética! O compilador não sabe quantos bytes pular. Declare sempre o tipo correto.
Vetor
*(v + i) == v[i]
As duas notações são equivalentes. Aritmética de ponteiros é a base de como vetores funcionam internamente em C.

Como o +1 funciona na prática

int* vs char*
C int v[5] = {10, 20, 30, 40, 50};
int *p = v; // p aponta para v[0]

printf("%d", *p); // 10 → v[0]
printf("%d", *(p + 1)); // 20 → v[1] (pulou 4 bytes)
printf("%d", *(p + 2)); // 30 → v[2] (pulou 8 bytes)

p++; // agora p aponta para v[1]
printf("%d", *p); // 20
Endereços em memória (int = 4 bytes cada):
v[0] ← p100010AA00
v[1]200010AA04
v[2]300010AA08
v[3]400010AA0C
v[4]500010AA10

Percorrer vetor com ponteiro (evolução do código)

Otimização
💡 O Prof. Moreno mostrou 4 versões progressivamente mais eficientes. A versão com ponteiro direto é a mais performática.
v1 · clássico (laço com índice) for (int i = 0; i < size; i++)
    if (nome[i] != '\0') contador++;
v4 · ponteiro direto (mais eficiente) char *p = nome;
while (*p != '\0') {
    contador++;
    p++;
}
// Ou ainda mais enxuto:
while (*p++) contador++; // ponteiro olha diretamente!

Aritmética com Matriz Dinâmica

2D
⚠ Matriz tem 2 dimensões. São necessárias 2 aritmética de ponteiros: uma para a linha, outra para a coluna.
C · ponteiro de ponteiro int **mat; // ponteiro de ponteiro

// Acessar mat[2][3] via aritmética:
*(*(mat + 2) + 3);
// ↑ aritmética linha ↑ aritmética coluna

// mat + 2 → endereço do ponteiro da linha 2
// *(mat + 2) → conteúdo = endereço início linha 2
// + 3 → avança 3 posições na linha
// *( ... ) → valor final
04 · Alocação Dinâmica
MEMÓRIA EM TEMPO DE EXECUÇÃO — STACK vs HEAP
"Em muitas situações é necessário alocar a memória em tempo de execução. Permite que o espaço em memória seja alocado apenas quando necessário." — Prof. Moreno
STACK (Pilha)
Variáveis locais de funções Tamanho fixo por thread Windows: ~1MB · Linux: ~8MB Desaparece ao fim da função → automático, não você
HEAP (Dinâmica)
malloc / calloc / realloc Cresce conforme necessário Pode usar GBs de RAM Persiste além da função → você gerencia com free()
⚠ De quem é a responsabilidade de liberar a memória alocada dinamicamente? Do programador! A região ficará marcada como ocupada até ser liberada ou o programa encerrar.

As 3 Funções de Alocação

stdlib.h
Função Parâmetros Inicializa? Uso principal
malloc() size_t bytes NÃO (lixo) Aloca N bytes; retorna void*
calloc() n, size SIM (zeros) Aloca n×size bytes zerados
realloc() ptr, novo_size Mantém dados Redimensiona bloco existente
free() ptr — Libera memória; obrigatório!

Vetor Dinâmico

Runtime
C int n;
scanf("%d", &n);

int *v = (int*) malloc(n * sizeof(int));
if (!v) { printf("Erro!"); return 1; }

for (int i = 0; i < n; i++) v[i] = i * 2;

free(v); // sempre!

Matriz Dinâmica — Vetor de Vetores

int**
ℹ Uma matriz dinâmica é um vetor de ponteiros. Cada posição do vetor aponta para outro vetor (a linha). Alocação em 2 etapas, liberação em 2 etapas.
C · Alocação int lin = 3, col = 4;

// Etapa 1: aloca vetor de ponteiros (linhas)
int **mat = (int**) malloc(lin * sizeof(int*));

// Etapa 2: para cada linha, aloca as colunas
for (int i = 0; i < lin; i++)
    mat[i] = (int*) malloc(col * sizeof(int));
C · Liberação (ordem inversa!) // Etapa 1: libera cada linha
for (int i = 0; i < lin; i++)
    free(mat[i]);

// Etapa 2: libera o vetor de ponteiros
free(mat);

// NUNCA faça free(mat) primeiro!
// As linhas ficarão órfãs e inacessíveis (memory leak!)

realloc — Redimensionando em Runtime

Realloc
💡 O realloc pode mudar o endereço do bloco se não houver espaço contíguo. Sempre salve o retorno em uma variável separada antes de sobrescrever o ponteiro original!
C · realloc seguro int *tmp = (int*) realloc(v, novo_n * sizeof(int));
if (!tmp) {
    printf("Falhou!"); // v ainda é válido!
} else {
    v = tmp; // atualiza apenas se deu certo
}
05 · Desafios
COLOCANDO EM PRÁTICA — 4 NÍVEIS DE DIFICULDADE
"Aqui, errar faz parte. O que não funciona é não tentar." — Prof. Moreno
⬢ Baixo
Troca com Ponteiros
Implemente uma função troca(int *a, int *b) que troque os valores de duas variáveis inteiras sem retornar nenhum valor.
O que praticar: passagem por referência, operador *, conceito de que a função altera a variável original via endereço.
💡 Dica: void troca(int *a, int *b). Use uma variável auxiliar: int aux = *a; *a = *b; *b = aux;
⬢ Baixo
Endereços do Vetor
Crie um vetor de 5 inteiros. Use aritmética de ponteiros para imprimir o endereço e o valor de cada posição sem usar o operador [].
O que praticar: aritmética de ponteiros, equivalência entre v[i] e *(v+i), formato %p para endereços.
💡 Dica: int *p = v; for(int i=0; i<5; i++) printf("%p %d\n", p+i, *(p+i));
⬡ Médio
Cadastro com Struct
Crie uma struct Aluno com nome, nota1, nota2, nota3 e media. Leia dados de 5 alunos, calcule a média e classifique por nome com bubble sort. Use ponteiro como parâmetro na função de ordenação.
O que praticar: struct, vetor de struct, ponteiro para struct como parâmetro (para que a troca funcione de verdade), strcmp para comparação de strings.
💡 Dica: void classifica(Aluno *v, int n). Use strcpy para copiar structs? Não! Aluno temp = v[i]; v[i] = v[j]; v[j] = temp; funciona porque structs podem ser atribuídas diretamente.
⬡ Médio
Maior e Menor com Ptr
Faça uma função minmax(int *v, int n, int *menor, int *maior) que encontre o menor e o maior elemento de um vetor. Retorne os dois valores via ponteiros de saída.
O que praticar: múltiplos valores de retorno via ponteiros, percorrer vetor com aritmética de ponteiros, inicialização com lixo de memória (como o Moreno mencionou).
💡 Dica: Inicialize *menor = v[0] e *maior = v[0], depois percorra de i=1 até n-1 comparando e atualizando. Chame com: minmax(v, 5, &min, &max);
◆ Alto
Vetor Dinâmico com Realloc
Crie um programa que leia números inteiros do usuário um a um (0 para encerrar). Use malloc/realloc para crescer o vetor conforme necessário. Ao fim, imprima todos e libere a memória.
O que praticar: malloc, realloc seguro (com ponteiro temporário), free, controle dinâmico de tamanho em runtime.
💡 Dica: Comece com int *v = malloc(sizeof(int)), size=0, cap=1. A cada inserção, se size == cap: cap *= 2; int *tmp = realloc(v, cap * sizeof(int)); if(tmp) v = tmp; Nunca faça v = realloc(v, ...) diretamente!
◆ Alto
Inverter String com Ptrs
Implemente uma função que inverta uma string no próprio vetor (sem cópia) usando apenas aritmética de ponteiros — sem usar índices com []. Retorne a quantidade de caracteres invertidos.
O que praticar: dois ponteiros caminhando pelas extremidades (técnica clássica), aritmética de ponteiros pura, manipulação de string sem índices.
💡 Dica: char *ini = s; char *fim = s; while(*fim) fim++; fim--; while(ini < fim) { char tmp = *ini; *ini = *fim; *fim = tmp; ini++; fim--; }
★ Altíssimo
Matriz Dinâmica de Structs
Crie uma matriz dinâmica de structs Produto (código, nome[50], preço). Leia as dimensões em runtime, preencha, ordene cada linha pelo preço com bubble sort usando ponteiro de ponteiro. Libere tudo corretamente.
O que praticar: ponteiro triplo conceitual (Produto**), alocação em 2 etapas, aritmética em 2 dimensões, função de ordenação recebendo Produto* (linha), liberação na ordem inversa.
💡 Dica: Typedef produto. Produto **mat = malloc(lin * sizeof(Produto*)). Para cada i: mat[i] = malloc(col * sizeof(Produto)). Função: void ordena_linha(Produto *linha, int n). Liberação: for(i) free(mat[i]); free(mat);
★ Altíssimo
Calculadora de sizeof + Padding
Crie 5 structs com campos de tipos misturados (char, short, int, double). Para cada uma: calcule manualmente o tamanho esperado considerando padding, depois confirme com sizeof(). Identifique onde o padding ocorre e prove reordenando os campos para minimizar o tamanho.
O que praticar: regras de padding (alinhamento interno + tamanho múltiplo do maior tipo), offsetof() da stddef.h, efeito da ordem dos campos no tamanho final da struct.
💡 Dica: Use offsetof(struct X, campo) para ver onde cada campo começa. Regra de ouro: ordene os campos do maior para o menor tipo para minimizar padding (double, int, short, char). Confirme com __attribute__((packed)) vs versão normal.
